# ✈️ Jornada Viagens: Experiência Responsiva Completa

> **Status do Projeto:** Concluído ✅

O **Jornada Viagens** é um site institucional focado no setor de turismo, desenvolvido para oferecer uma navegação fluida em qualquer dispositivo. O projeto destaca o uso de **HTML5 Semântico** e uma arquitetura CSS modular e escalável, garantindo alta performance e facilidade de manutenção.

## 🚀 Diferenciais Técnicos

Este projeto foi construído utilizando as melhores práticas de desenvolvimento Front-End:

* **Arquitetura CSS Modular:** Organização inteligente onde cada seção possui suas próprias declarações de estilo, facilitando a manutenção e evitando conflitos.
* **Variáveis Globais (`:root`):** Uso de variáveis CSS para gerenciar cores e fontes de forma centralizada, garantindo consistência visual em todo o site.
* **Responsividade Total:** Implementação rigorosa de **Media Queries** para garantir que a interface fique impecável em dispositivos Mobile, Tablets e Desktops.
* **HTML5 Semântico:** Estruturação pensada em acessibilidade e SEO, utilizando as tags corretas para cada tipo de conteúdo.
* **Estilos Globais:** Padronização de elementos comuns através de um arquivo de estilos globais bem definido.
